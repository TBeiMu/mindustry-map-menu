# Map Menu

适用于 Mindustry 8 build 159.7 的服务器“地图管理器”插件。

## 功能

- `/maps` 打开游戏内地图选择菜单，分页显示服务器全部地图
- 显示地图类型：`[自定义]`、`[内置]`、官方 PVP 地图显示核心阵营数（如 `[内置 2人PVP]`）
- 既能点击菜单选择，也能用 `/map <编号>` 或 `/map <名称>` 直接输入选择
- 选择地图后可选择生存、沙盒、进攻、PVP 模式；进入 PVP 地图后，所有玩家会自动看到选队菜单
- PVP 选队菜单只显示地图上实际存在核心的队伍，并在按钮上显示当前人数；选队后最大、最小队伍人数差不得超过 2
- 玩家中途加入 PVP 也会自动弹出选队菜单；误关后可输入 `/team` 重新打开
- 管理员选择后直接进入换图倒计时；普通玩家发起换图投票，避免管理员单方面换图
- 投票人数、投票时长、换图冷却、切换倒计时均可配置（命令或管理员菜单）
- 可设置默认地图、随机换图、地图轮换
- 所有管理命令/菜单仅限管理员使用，普通玩家无法使用管理功能
- 管理员菜单可一键暂停/继续游戏
- 存档管理：10 个手动存档栏位，可保存/读取，存档存放于服务器 config/saves 文件夹（与 maps 互不干扰）
- v2.5.1：读取存档后自动清除存档中恢复的数据资产，并输出诊断日志（防止含内容MOD时期存档导致玩家重连时客户端世界流解压崩溃）
- v2.6.1：修复切换到 PVP 地图时，原有玩家因客户端仍在加载世界而收不到自动选队菜单的问题

## 命令（游戏内聊天框输入）

| 命令 | 说明 | 权限 |
| --- | --- | --- |
| `/maps` | 打开地图选择菜单 | 所有玩家 |
| `/map <编号\|名称>` | 按编号或名称直接选择地图 | 所有玩家 |
| `/mapvote` | 查看当前换图投票并投赞成/撤票 | 所有玩家 |
| `/team` | 打开当前 PVP 地图的选队菜单 | 所有玩家 |
| `/mmconfig` | 查看当前地图管理配置 | 所有玩家 |
| `/admin` | 打开管理员地图管理菜单 | 管理员 |
| `/setvotes <票数\|majority>` | 设置换图所需票数（majority = 多数票） | 管理员 |
| `/setvotetime <秒>` | 设置投票时长 | 管理员 |
| `/setcooldown <秒>` | 设置换图冷却时间 | 管理员 |
| `/setcountdown <秒>` | 设置切换倒计时秒数 | 管理员 |
| `/setdefault <编号\|名称\|off>` | 设置或清除默认地图 | 管理员 |
| `/setrandom <on\|off>` | 开启或关闭随机换图 | 管理员 |
| `/setrotation <编号列表\|off>` | 设置地图轮换列表（空格分隔） | 管理员 |
| `/mmrestart` | 重启当前地图 | 管理员 |

管理员菜单（`/admin`）可直接设置默认地图、轮换、随机换图、投票参数，并可暂停/继续游戏、重启地图、管理 10 个手动存档栏位。
编号与 `/maps` 菜单中的编号一致。

## 安装

1. 停止服务器。
2. 将 `MapMenu.jar` 上传到 `/home/container/config/mods/`。
3. 将 `.msav` 地图放到 `/home/container/config/maps/`。
4. 启动服务器，在控制台确认出现 `[MapMenu] Loaded`。
5. 进入游戏输入 `/maps`。


## 从源码构建

需要 JDK 17 或更高版本。将服务器中的 `config/mods/Mindustry.jar` 放入
项目的 `libs/Mindustry.jar`，然后执行：

```text
gradle clean jar
```

生成的插件位于 `build/libs/MapMenu.jar`，仓库根目录 `outputs/MapMenu.jar` 为当前构建产物。
